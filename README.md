# 길이 척척

조각을 이어 붙여 다리를 놓는 6~9세용 길이 개념 게임.
WTPP PLAY의 여섯 번째 서비스다.

## 어떻게 노는가

1. 계곡에 끊긴 다리가 있고, 몇 칸이 비었는지 알려준다
2. 아래 조각을 눌러 다리에 착 붙인다
3. 딱 맞으면 다리가 완성되고 수레가 건넌다
4. 잘못 놓았으면 그 조각을 눌러 빼면 된다. 틀려도 게임이 끝나지 않는다
5. 끝나면 최고 점수가 남고, 기록을 사진 한 장으로 저장할 수 있다

목표를 만드는 방법은 여럿이다. 8칸은 4+4로도, 2+2+2+2로도, 5+3으로도 만들어진다.
**길이는 정해진 단위가 반복된 양**이라는 감각을 손으로 익히는 것이 이 게임의 목적이다.

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 타입 검사 + 빌드
npm test           # 단위 테스트
npm run lint       # oxlint
```

## 구조

```
src/
├─ config/gameConfig.ts   난이도·규칙·조각 색. 숫자를 고칠 일은 대부분 여기
├─ lib/
│  ├─ problems.ts         문제 생성 ← 게임을 늘릴 때 손대는 곳
│  ├─ feedback.ts         Web Audio 효과음과 진동
│  ├─ resultImage.ts      결과를 사진 한 장으로 (기기 안에서 그린다)
│  └─ storage.ts          최고 점수·설정 (이 기기 안에만 남는다)
├─ components/            자, 조각, 버튼, 링크
└─ screens/               첫 화면 · 게임 · 결과
```

설계 배경과 확장 방법은 `CLAUDE.md`에 적어 두었다.
