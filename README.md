# 길이 척척

조각을 이어 붙여 다리를 놓는 6~9세용 길이 개념 게임.
WTPP PLAY의 여섯 번째 서비스다.

## 어떻게 노는가

1. 계곡에 끊긴 다리가 있고, 몇 칸이 비었는지 알려준다
2. 아래 조각을 눌러 다리에 착 붙인다
3. 딱 맞으면 다리가 완성되고 수레가 건넌다
4. 잘못 놓았으면 그 조각을 눌러 빼면 된다. 틀려도 게임이 끝나지 않는다
5. 끝나면 최고 점수가 남고, 기록을 사진 한 장으로 저장할 수 있다

목표를 만드는 방법은 여럿이다. 8칸은 4+4로도, 2+2+2+2로도, 5+3으로도 만들어진다.
**길이는 정해진 단위가 반복된 양**이라는 감각을 손으로 익히는 것이 이 게임의 목적이다.

## 무엇을 배우나

단계가 올라가면 다루는 수가 커지는 게 아니라 **만나는 개념이 늘어난다.**

| 단계 | 새로 만나는 것 |
|---|---|
| 쉬움 | 자로 재기, 이어 붙이기, 한 조각 × 개수 → 전체, 전체 ÷ 한 조각 → 개수 |
| 보통 | 전체 ÷ 개수 → 한 조각, 같은 길이를 다른 단위로 재기 |
| 어려움 | 0이 아닌 눈금에서 재기, 선분의 부분 구하기, 양쪽에서 같은 것 지우기, 꺾인 길, 수직선 |
| 도전 | 겹치는 구간, 여러 번 꺾인 길 (새 조작은 없다) |

문제가 열두 가지지만 **조작은 둘뿐이다** — 틈을 채우거나, 눈금을 짚거나.
새 개념을 만날 때마다 조작을 다시 배우지 않아도 된다.

기억에 남게 하려고 몇 가지는 화면이 대신 말한다.
꺾인 길은 맞히면 그 자리에서 쭉 펴져 아래 다리와 나란해지고,
수직선은 짚을 때마다 양쪽 거리가 화살표로 나와 두 숫자가 같아지는 자리를 찾게 한다.
두 줄 견주기는 양쪽에 똑같이 있는 물건을 눌러 지워 나가면 남은 것끼리 답이 보인다.

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 타입 검사 + 빌드
npm test           # 단위 테스트
npm run lint       # oxlint
```

## 구조

```
src/
├─ config/gameConfig.ts   난이도·규칙·조각 색. 숫자를 고칠 일은 대부분 여기
├─ lib/
│  ├─ problems.ts         문제 생성 ← 게임을 늘릴 때 손대는 곳
│  ├─ feedback.ts         Web Audio 효과음과 진동
│  ├─ resultImage.ts      결과를 사진 한 장으로 (기기 안에서 그린다)
│  └─ storage.ts          최고 점수·설정 (이 기기 안에만 남는다)
├─ components/            자, 조각, 수직선, 꺾인 길, 두 줄 견주기, 버튼, 링크
└─ screens/               첫 화면 · 게임 · 결과
```

설계 배경과 확장 방법은 `CLAUDE.md`에 적어 두었다.
